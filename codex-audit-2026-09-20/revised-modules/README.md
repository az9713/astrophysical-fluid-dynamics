# Codex textbook rewrite: Modules 1–12

These files are paragraph-level textbook rewrites of `afd/module01.html` through
`afd/module12.html`. The source modules remain unchanged. The rewrite preserves
the audited mathematics, figures, citations and scientific corrections while
removing production narration, synthetic rhetoric and overloaded exposition.

Open `index.html` to read the edition. `build-manifest.json` records every
applied content finding, prose edit and dependent repair. The reproducible
scientific-correction builder is `../build_revised_modules.py`. The prose pass is
`../humanize_revised_modules.py`. Structural and prose validation are provided by
`../validate_revised_modules.py` and `../validate_prose_rewrite.py`.
